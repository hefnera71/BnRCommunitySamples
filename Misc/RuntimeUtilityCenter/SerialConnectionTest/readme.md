# About
This PIL instruction list can be used with Runtime Utility Center (RUC, aka PVITransfer) to determine serial online communication parameters of legacy B&R PLCs.

Just for use with **Version 4.x** of Runtime Utility Center (as the protocol INA is no longer supported with Versions >= 6.x of PVI).

For documentation and details, see the this [BnR Community Post](https://community.br-automation.com/t/determine-serial-online-connection-parameters-sg3-legacy-systems/2662).
