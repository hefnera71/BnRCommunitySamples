# BnRCommunitySamples / Misc

The section "Misc" is used for tools outside of Automation Studio, but still having some dependency to AS / AR.

### All content in this repository was developed for my private projects or educational reasons. 


## Description

Here's a very short description about the content of each package:
* **"AsOutputAnalyze"** - Windows program to structure Automation Studio build logs (how to use: see [README.md](https://github.com/hefnera71/BnRCommunitySamples/blob/master/Misc/ASOutputAnalyse/readme.md) )
* **"LoadSysDump"** - CMD-file using cURL to load a system dump for the PLC ([README.md](https://github.com/hefnera71/BnRCommunitySamples/blob/master/Misc/LoadSysDump/readme.md) )
* **"RuntimeUtilityCenter"** - a collection of RUC samples published via B&R Community
  * **"RandomWaitInPil"**: PIL + CMD-file to wait a random count of seconds in RUC batch process ([README.md](https://github.com/hefnera71/BnRCommunitySamples/blob/master/Misc/RuntimeUtilityCenter/RandomWaitInPil/readme.md))
  * **"CounterInPil"**: PIL + CMD-file to count in RUC batch process ([README.md](https://github.com/hefnera71/BnRCommunitySamples/blob/master/Misc/RuntimeUtilityCenter/CounterInPil/readme.md))
  * **"SerialConnectionTest"**: PIL-file to probe serial online connection parameters ([README.md](https://github.com/hefnera71/BnRCommunitySamples/blob/master/Misc/RuntimeUtilityCenter/SerialConnectionTest/readme.md))
